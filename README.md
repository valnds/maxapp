# MAX App

Статический многостраничный сайт на HTML, CSS и JavaScript. Сборка и сервер не требуются.

## Публикация на GitHub Pages

1. Загрузите файлы проекта в корень GitHub-репозитория.
2. Убедитесь, что основная ветка называется `main`.
3. Откройте **Settings → Pages** и в разделе **Build and deployment** выберите **GitHub Actions**.
4. После push в `main` откройте **Actions** и дождитесь успешного завершения `Deploy static site to GitHub Pages`.
5. Адрес сайта появится в **Settings → Pages** и в деталях workflow.

Главная страница сайта — `index.html`. Страницы и изображения используют относительные пути, поэтому работают как на пользовательском сайте, так и в проектном репозитории вида `https://<username>.github.io/<repository>/`.

Данные приложения сохраняются в `localStorage` браузера. GitHub Pages предоставляет статическую раздачу файлов и не хранит пользовательские данные на сервере.
